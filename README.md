# 🏨 Hotel Management SQL Project

A complete SQL database project for managing hotel operations.

## 📌 Project Overview

This project demonstrates a Hotel Management Database System using SQL.
It includes database schema design, sample data, queries, views,
stored procedures, and triggers.

## 🗂️ Project Structure

- 01_schema.sql - Database and table creation
- 02_data.sql - Sample data insertion
- 03_queries.sql - SQL queries and reports
- 04_views.sql - Database views
- 05_procedures.sql - Stored procedures
- 06_triggers.sql - Database triggers

## 🛠️ SQL Concepts Used

- Database Design
- Primary Keys
- Foreign Keys
- Constraints
- INSERT / UPDATE / DELETE
- SELECT Queries
- JOINs
- GROUP BY
- Aggregate Functions
- Views
- Stored Procedures
- Triggers

## 🎯 Objective

The objective of this project is to design and implement a
relational database for managing hotel operations efficiently.
